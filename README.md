# TASL Voice

**TASL Voice** is the voice-production module of the TA Studio Loop (TASL) system.

It is a Windows application for turning English scripts into production-ready voice audio and subtitles for long-form storytelling workflows.

**Current stable public version: v1.1.2**

## What TASL Voice does

- Converts scripts into **MP3 + SRT** output
- Manages a reusable **voice library**
- Supports **multi-character voice assignment**
- Provides queue, stop, resume and reprocess workflows
- Includes quality-review signals for generated speech
- Supports local **NVIDIA hardware acceleration**
- Checks for updates and supports recovery/rollback paths

## Designed for production use

TASL Voice is built for repeatable media-production workloads rather than one-off text-to-speech generation. It is used as the voice stage inside a broader production workflow that connects scripting, scene planning, media generation, rendering and publishing operations.

## System requirements

- Windows 10 or Windows 11, 64-bit
- NVIDIA GPU recommended for practical processing speed
- 8 GB+ GPU memory recommended
- 15 GB+ free disk space recommended
- Internet connection required during installation
